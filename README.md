# 2D-игра «Побег из тюремного блока»

Небольшая 2D-игра на HTML5 Canvas с коротким сюжетом:

1. Герой в тюремной камере.
2. Нужно активировать рычаг и открыть путь.
3. Найти ключ-карту на посту охраны.
4. Открыть главные ворота и сбежать.

Персонаж выполнен как черный силуэт.

## Как запустить

### Вариант 1: просто открыть файл

Открой `index.html` в браузере.

### Вариант 2: через локальный сервер (рекомендуется)

```bash
python3 -m http.server 8000
```

После запуска открой:

`http://localhost:8000`

## Управление

- `A / D` — движение
- `W` или `Space` — прыжок
- `E` — взаимодействие (рычаг, дверь)
- `R` — перезапуск
